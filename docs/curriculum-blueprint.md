## Content schema to use next

Each lesson should eventually be stored as structured data with these blocks:

- `overview`: lesson number, theme, situations, learning goals
- `vocabulary`: Korean, English, POS, Hanja/Chinese when relevant, example, audio, image, tags
- `expressions`: high-frequency fixed or pragmatic expressions
- `grammar`: form, meaning, formation, usage, examples, contrast, common mistakes, related systems
- `culture`: concise original cultural/pragmatic notes
- `practice`: original MCQ, typing, sentence-building, listening, role-play prompts
- `teacherFocus`: material emphasized in the teacher PPT
- `connections`: links to other lessons and Explore system pages
