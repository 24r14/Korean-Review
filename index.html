    Shared content source

    Everyone using this site can share the same vocabulary and grammar by pulling it from a shared Google Sheet. Your own flashcard progress and any personal notes always stay local to your browser — only the base content is shared.

    1. In Google Sheets, create one spreadsheet with 3 tabs named Lessons, Vocabulary, Grammar.
    2. Lessons tab needs a column name. Vocabulary needs lesson, korean, pos, meaning, origin, example, image (origin and image are optional; put more than one example per cell on separate lines within the cell — press Alt+Enter in Google Sheets to add a line break inside a cell). Grammar needs lesson, pattern, explain, example (same multi-line trick works for example).
    3. File → Share → Publish to web. For each of the 3 tabs, choose that tab and "Comma-separated values (.csv)", then copy the link.
    4. Paste the 3 links below and save. Anyone you share edit access to the Sheet with can add content, and it shows up here next time the site loads.
